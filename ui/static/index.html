Vault

Checking the vault…

Lock browser forgets the unlocked vault in this browser only; approved agent windows keep running until they end. Stop access ends one window. Lock all execution ends every window for your account.

Set up your vault

  1. Choose a passphrase
  2. Save the recovery key
  3. Confirm and finish

The vault passphrase is separate from your account password and never leaves this browser. The gateway stores only encrypted data.

Use at least 15 characters, and not your account password. Spaces and letter forms are kept exactly as typed.

This recovery key unlocks your vault if you forget the passphrase. It is shown once. Write it down or store it in a password manager, away from this device.

Anyone with this key can decrypt your vault. The gateway cannot recover it for you.

Type the recovery key you saved to confirm it works. Setup finishes only after this check.

Your account password confirms this change with the gateway. It is not used to encrypt the vault.

    Connect an MCP client
    1. Create a Client API key below, or authorize through your configured OAuth provider.
    2. Choose Streamable HTTP in your MCP client and enter your gateway URL ending in /mcp. For this local Compose setup, use http://localhost:8787/mcp; hosted installations use their public gateway URL.
    3. Paste your API key into the client’s bearer-token field, or complete its OAuth flow. Keep credentials out of the URL.
    Connect MCP clients to your gateway’s /mcp endpoint using an API key or OAuth token. Client access includes enabled upstream tools and provider refresh. Admin access also includes management tools and the management API.
